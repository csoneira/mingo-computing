# ANCILLARY

This directory holds Digital Twin operations and analysis utilities that do
not belong to a specific simulation step. See the source-tree
[`ANCILLARY/README.md`](../../../../../PIPELINE/MINGO_DIGITAL_TWIN/ANCILLARY/README.md)
for the current inventory and safety notes.

## Canonical orchestration scripts

Operational scripts are maintained under:

- `PIPELINE/MINGO_DIGITAL_TWIN/ORCHESTRATOR/core`
- `PIPELINE/MINGO_DIGITAL_TWIN/ORCHESTRATOR/maintenance`
- `PIPELINE/MINGO_DIGITAL_TWIN/ORCHESTRATOR/helpers`

Former compatibility wrappers from this directory have been removed from the
active tree. The previous `.ATTIC/ANCILLARY/` location is no longer present.
