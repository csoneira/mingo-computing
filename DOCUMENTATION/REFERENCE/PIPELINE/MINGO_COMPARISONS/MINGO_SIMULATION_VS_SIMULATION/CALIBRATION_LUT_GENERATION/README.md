# Calibration LUT generation from simulation

This area is reserved for simulation-versus-simulation studies that derive candidate calibration lookup tables using simulated events and simulation truth. No generator is implemented here yet.

Keep the derivation, inputs/configuration references, validation, and provenance with the study. After a candidate LUT is reviewed for use in reconstruction, place the analysis-facing LUT and its usage documentation under:

`PIPELINE/MINGO_ANALYSIS/MINGO_ANALYSIS_SCRIPTS/ANCILLARY/CALIBRATIONS_AND_LUTS/SIMULATION_DERIVED_LUTS/`

Do not treat an unvalidated candidate as an active calibration.
