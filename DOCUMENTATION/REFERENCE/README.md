# Repository reference documentation

This directory collects operator guides, code-component manuals, scientific study notes, and historical report documentation that were previously scattered beside scripts and configurations. The mirrored subdirectories preserve each document’s original repository context.

The published documentation site remains under `DOCUMENTATION/docs/`. Repository-specific reference material here is kept in the documentation tree but is not necessarily published online.

The root `README.md` remains the repository landing page. `legacy/` retains historical archive documentation in place, and generated runtime/cache reports remain with their data.
