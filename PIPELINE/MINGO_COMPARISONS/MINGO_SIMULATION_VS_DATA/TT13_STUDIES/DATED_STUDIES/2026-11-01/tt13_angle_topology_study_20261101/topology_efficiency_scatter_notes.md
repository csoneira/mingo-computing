# Three-station strip-topology conditional-efficiency plots

The 9 topology gates are based on binary endpoint hit state (at least one Q endpoint != 0), not charge magnitude. The three scatter panels per gate show: closure vs configured simulation P2 efficiency; closure vs count-derived e2|P4-hit; and e2|P4-hit versus e2|P4-miss.

MINGO00 and MINGO01 reuse the previously audited event-gate counts. MINGO02 was recalculated from 144 files with acquisition-time-matched LIP voltage logs; it has two stable voltage groups.

These are conditional ratios in a triggered sample, not absolute intrinsic efficiencies. The large MINGO00/MINGO02 closure difference is a diagnostic, while topology acceptance differs greatly between simulation and data and several gates have sparse simulation counts.
