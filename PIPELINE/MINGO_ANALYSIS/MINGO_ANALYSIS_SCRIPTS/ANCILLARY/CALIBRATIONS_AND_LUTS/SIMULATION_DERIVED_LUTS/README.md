# Simulation-derived calibration LUTs

This directory is reserved for reviewed lookup tables derived from simulation and intended for calibration or reconstruction in `MINGO_ANALYSIS`. No LUTs are installed here yet.

Keep each LUT's source study, simulation/configuration provenance, validation status, expected schema, and consuming calibration configuration documented alongside it. Candidate derivation work belongs in `PIPELINE/MINGO_COMPARISONS/MINGO_SIMULATION_VS_SIMULATION/CALIBRATION_LUT_GENERATION/`.
