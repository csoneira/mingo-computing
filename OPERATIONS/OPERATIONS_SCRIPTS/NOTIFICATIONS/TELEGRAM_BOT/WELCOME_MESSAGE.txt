MINGO metadata plotting bot

/plot_metadata_gui - choose station, task, metadata CSV, numeric column, and date basis using buttons.
/plot_metadata_cli - choose the same options by replying with numbers.
/round_in_the_chamber - send the newest file staged in the bot-local GUN_CHAMBER folder.

Choose execution / processing date or acquisition / data date. Lookback accepts fractional days, from greater than 0 up to 3650 days.

Reply `cancel` at any prompt to stop. Use /help to show this guide.
