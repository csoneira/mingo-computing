# Angle-gated P2 efficiency scatter plots

Each gate has three panels: closure versus configured simulation P2 efficiency; closure versus count-derived e2 conditional on P4 hit; and e2 conditional on P4 hit versus e2 conditional on P4 miss.

MINGO00 uses reconstructed P1/P3 angle and reconstructed all-four fiducial in the scatter pages, for station comparability. The front-page simulation validation uses truth angle and true geometric intersections. MINGO01/02 use reconstructed P1/P3 angle and reconstructed all-four fiducial. Definitions are in the PDF.

Gate rows are exclusive angle bins and cumulative lower-angle cuts. The 45–90 degree fiducial cells are empty; that page explicitly demonstrates the absence of valid events and should not be interpreted as an efficiency measurement.
