# Energy from timing studies

This area contains standalone investigations of muon energy and velocity estimates from timing or time-of-flight measurements. These studies are independent of the production MINGO event-processing pipeline.

- `HISTORICAL/energy_from_timing_ar18.py` is preserved from the curated TRASGO tools archive. Its source blob is recorded in `legacy/TRASGO_TESTS_AND_TOOLS/ARCHIVE_MANIFEST.md`.
- [`../MUON_TOF_ENERGY_RECONSTRUCTION`](../MUON_TOF_ENERGY_RECONSTRUCTION/) contains the later, documented TOF scan implementation.

Keep historical and later implementations distinguishable. This directory is for research code and results, not production calibration or reconstruction inputs.
